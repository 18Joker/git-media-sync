# Git 媒体下载器 设计文档

## 意图与背景

Git 项目里的图片/视频等媒体素材不适合进仓库。用户用**阿里云盘自带的自动备份**把整个项目文件夹（含 git 未管理的文件）上传到云盘；本工具负责在**另一台电脑**把这些 git 未管理的媒体文件按原目录层级下载回本地项目，保证跨设备项目媒体一致。

本工具**只做下载**，不做上传。

## 目标

- 单个 exe，拷到另一台电脑双击即用（无需装 Python）。
- 项目级管理：预先配置多个项目，点选即可同步。
- 扫码登录阿里云盘。
- 树形、可勾选的文件清单，自由决定下载哪些。
- 覆盖式增量下载：相同文件跳过，不同则覆盖，保留目录层级。

## 非目标（不做）

上传、文件级数据库/云端清单、版本管理、自动删除本地文件、多账号管理、跨平台打包（Windows 优先，代码尽量跨平台）。

## 约束

- Python 3.12；GUI 仅用标准库 Tkinter/ttk，不引入其它 GUI 框架（保持轻量）。
- 云存储仅经 `aligo` 6.2.8 封装，不直接裸调阿里云盘 API。
- 打包：PyInstaller `--onefile --windowed`，产物为单个 exe。
- 配置用 JSON（项目数量少，无需 SQLite）。

## 方案选型

- **UI：Tkinter**。曾考虑 pywebview / Flet / PySide6：Qt 太重（100MB+）违背轻量；pywebview/Flet 引入额外运行时或 JS 层。Tkinter 零额外 UI 依赖、打包最小，最适合这个小工具。
- **存储：aligo**。提供扫码登录（`Aligo(show=回调)`）、`get_file_list`（自动翻页）、`get_file_by_path`、`download_file`。
- **配置：JSON**。项目几个到几十个，JSON 足够且可手工拷贝复用。

## 关键决定

- **下载范围**：跳过 git 已跟踪文件（`git -C <local> ls-files -z`），并始终跳过 `.git/`。只下载 git 未管理（忽略/未跟踪）的文件，保护源码。本地不是 git 仓库或未装 git → 明确报错停止。
- **比对**：按 `size`。本地缺失=`待下载(pending)`；存在但大小不同=`将覆盖(overwrite)`；大小相同=`已相同(same)`，默认不勾选。
- **覆盖实现**：aligo 的 `download_file` 遇到已存在文件会**跳过**，因此覆盖必须**先下载到临时目录，再 `os.replace` 替换目标**（原子、不留半截文件、下载失败不破坏原文件）。
- **只增不删**：不删除本地任何文件（覆盖替换除外）。
- **登录**：`Aligo(show=回调)` 扫码；回调收到二维码链接字符串，送到 GUI 用 `qrcode` 渲染；aligo 内部轮询扫码状态。备用 `refresh_token` 粘贴登录。token 由 aligo 缓存于 `~/.aligo`。登录在后台线程，GUI 不阻塞。
- **配置**：`config.json` 存项目列表（名称/云盘路径/本地路径）+ 上次选中项目；存于 `app_dir()`（打包后 exe 旁，开发时项目根）。名称唯一，默认取本地文件夹名。
- **GUI**：左侧项目列表 + 增/删/改；右侧云盘/本地路径 + 登录 + 工具栏 + 树形清单（Treeview 三态勾选）+ 日志。所有耗时操作在后台线程，GUI 更新经 `queue` + `after`。
- **windowed 兼容**：`--windowed` 下 `sys.stdout/stderr` 可能为 None，会导致 aligo 的 tqdm/coloredlogs 崩溃；启动时重定向到日志文件。
